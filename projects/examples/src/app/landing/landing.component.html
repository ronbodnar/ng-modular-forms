ng-modular-forms

A lightweight architectural layer for Angular Reactive Forms. Engineered for orchestration, reactive isolation, and scalable composition.

View interactive examples →

Features / Benefits

Move enable/disable flows and dependent field logic into reusable handlers. Stop scattering valueChanges across component lifecycle hooks. A dedicated layer for API transformations. Use mappers to convert complex JSON into structured form states and back again with type-safety. Consistent declarative components built on CVA. Swap between native and UI implementations (like Material) without touching your core logic. Engineered for ERP systems and administrative tools where standard forms inevitably become a technical debt burden.
